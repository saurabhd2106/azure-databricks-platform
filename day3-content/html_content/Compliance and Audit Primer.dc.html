Compliance and audit logging: set a secure baseline, then prove it holds

A security baseline is the set of controls every workspace must have. The compliance security profile hardens the compute that runs your code. Audit logs record who did what, so you can show an auditor that the controls work.

LEARNING OBJECTIVE Describe the compliance security profile, how to establish a platform security baseline, and the difference between the audit system table and diagnostic log delivery.
01

Why: what goes wrong without them

Why a compliance baseline?

Every workspace starts with sensible defaults, but regulated data needs more, and it needs the same controls everywhere. Without a baseline, each team configures its own workspace and the weakest one sets your real security level.

Why audit logs?

Permissions say who could act. Audit logs record who did: every sign-in, grant, query and secret read. They are the evidence for auditors and the first thing you need in an incident.

02

The compliance security profile

The compliance security profile (CSP) is a workspace setting for processing regulated data such as health records (HIPAA) or card data (PCI-DSS). It changes the compute plane: cluster VMs run a hardened image with security monitoring agents and are patched on a fixed schedule. It requires the Premium plan and the Enhanced Security and Compliance add-on.

Establishing a platform security baseline

A baseline is a written list of controls applied to every workspace, deployed as code so it can't drift. Controls are configured in four places: Entra ID, Azure, the Databricks account and each workspace. Tick each control to assess a workspace.

Turn on verbose audit logs
A workspace setting that adds the text of every notebook command and SQL query to the audit events. Without it you can see that a notebook ran, but not what it did. It applies to both delivery methods.
Recommended: use both
Send diagnostic logs from every workspace to Log Analytics or Sentinel for real-time alerting and long retention the security team controls. Give data platform admins SELECT on system.access for investigation, usage reports and account-level events.
