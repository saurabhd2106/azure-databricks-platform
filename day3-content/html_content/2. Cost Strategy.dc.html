01 · COST MODEL

Every invoice has two meters

Most cost reviews look only at the DBU line, because that is what the Databricks usage dashboard shows. Azure infrastructure is frequently 40–60% of the total.

Databricks Units{{ dbuPct }}%
Azure infrastructure{{ infra }}%
Billed by Databricks, via the Azure Marketplace Driven by compute type (Jobs, All-Purpose, SQL Warehouse, Serverless), the runtime used, and hours running.
Billed by Microsoft Azure directly Driven by VM family and size, managed disks, storage (ADLS), networking, NAT Gateway and egress.
Single DBU-based ratecompute included

Serverless compute (SQL, jobs and notebooks) collapses both meters into one rate. Attribution gets simpler, and the optimisation levers shift from infrastructure tuning toward workload efficiency and warehouse sizing.
A complete view requires joining Databricks usage data with the Azure Cost Management export for the same subscriptions.
